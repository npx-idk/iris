# Security Policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, email **dalavai.hari@gmail.com** with:

- A description of the vulnerability and its impact
- Steps to reproduce
- Any suggested fix, if you have one

You will receive a response within a few days. Please give us a reasonable window to ship a fix before disclosing publicly.

## Scope

Iris is self-hosted software. Vulnerabilities in the API (auth bypass, privilege escalation across projects/workspaces, API-key scoping), the web app (XSS, CSRF), and the CLI are all in scope.
