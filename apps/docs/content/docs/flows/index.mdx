---
title: Flows
description: Orchestrate multiple tests on a visual node graph.
---

Flows let you arrange a project's tests on a node graph to define how they run together — which tests come first, and what depends on what. Iris derives the run order from the graph.

You'll find the flow editor inside each project under **Flows**.

<Callout title="Documentation in progress">
  A full guide to building and running flows is planned. For now, the editor
  itself is the best reference — create a flow in a project and experiment.
</Callout>
